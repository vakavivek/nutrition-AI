# Food Nutrition Assistant

A food nutrition app with a Streamlit frontend and a FastAPI backend.

## Requirements

- Python 3.10 or newer
- A Mistral API key
- Internet access for the first startup, when the CLIP model is downloaded

## Setup

From the project root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
